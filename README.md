# 📊 Excel Sales Performance Dashboard

An interactive Sales Dashboard built in Excel to analyze FY2025 sales performance across regions, products, and salespeople — designed for quick, data-driven business decision-making.

## 🎯 Objective
To consolidate raw transactional sales data into a clean, interactive dashboard that helps stakeholders track revenue trends, top-performing products/regions, and sales team performance at a glance.

## 🗂️ Dataset
- **Records:** ~1,500 sales transactions (FY 2025)
- **Fields:** Date, Region, Product, Salesperson, Units Sold, Unit Price, Revenue
- **Source:** Simulated dataset representing a multi-region electronics retail business

## 🛠️ Tools & Techniques Used
- **Excel Tables** – structured, dynamic data range
- **PivotTables & Slicers** – interactive filtering by Region / Product / Month
- **Formulas** – `SUMIFS`, `COUNTA` for live KPI and summary calculations
- **Charts** – Bar, Line, and Pie charts for visual storytelling
- **Dashboard Design** – KPI cards, color-coded sections, clean layout

## 📈 Key Features
- 4 dynamic KPI cards: Total Revenue, Units Sold, Transactions, Avg Order Value
- Region-wise, Product-wise, Salesperson-wise, and Month-wise revenue breakdown
- Interactive charts: Revenue by Region (Bar), Revenue Share by Product (Pie), Monthly Trend (Line), Salesperson Performance (Bar)
- Fully formula-driven — dashboard auto-updates when source data changes

## 🚀 How to Use
1. Download `Sales_Dashboard.xlsx`
2. Open in Microsoft Excel
3. Go to the **Sales Data** sheet to explore raw data (formatted as an Excel Table)
4. View the **Dashboard** sheet for KPIs, summary tables, and charts
5. (Optional) Insert your own PivotTable/Slicer: click inside the table → Insert → PivotTable → Insert → Slicer
